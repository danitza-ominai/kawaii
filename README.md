# Your Kawaii Closet

Your Kawaii Closet es un prototipo interactivo de una tienda online de ropa kawaii ecuatoriana.

El proyecto fue diseñado inicialmente en Figma y posteriormente desarrollado como una aplicación web estática en HTML, CSS y JavaScript.

## Demo

- Prototipo en Figma: [Ver prototipo](https://www.figma.com/proto/n5AqOYpkawnXpI7TN9fSUD/Sin-t%C3%ADtulo?node-id=4-812&t=cPGQeaOqNKGuUYmW-1)
- Sitio publicado: `Pegar aquí la URL de Netlify`

## Características

- Página de inicio con identidad visual kawaii.
- Catálogo de productos con filtros.
- Fichas de producto con precio, stock y tallas.
- Creador de avatar en tres pasos:
  - Medidas.
  - Apariencia.
  - Avatar listo.
- Probador virtual.
- Recomendación de talla según las medidas ingresadas.
- Carrito funcional en memoria.
- Cálculo de subtotal, envío y total.
- Checkout simulado en tres pasos.
- Métodos de pago:
  - Tarjeta.
  - Payphone.
  - Deuna.
  - Transferencia.
- Pantalla de confirmación del pedido.
- Diseño responsive y mobile-first.
- Precios expresados en dólares estadounidenses.
- Envíos a todo Ecuador.
- Cambio gratis por primera vez.
- Pago seguro.
- No utiliza `localStorage` ni solicita datos personales de menores.

## Ejecución local

Este proyecto no necesita instalar dependencias ni configurar una API.

Para ejecutarlo localmente:

1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en un navegador web.

También se puede ejecutar utilizando una extensión como Live Server en Visual Studio Code.

## Publicación en Netlify

Para publicar el proyecto:

1. Descargar el archivo ZIP del proyecto.
2. Ingresar a Netlify Drop.
3. Arrastrar el archivo ZIP o la carpeta del proyecto.
4. Verificar que el archivo principal se llame `index.html`.
5. Copiar la URL pública generada por Netlify.
